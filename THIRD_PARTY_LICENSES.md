# Third-Party Dependencies & Prior Art Attribution

NATIVEON is built from scratch without external GPU compute or AI framework dependencies (such as CUDA, PyTorch, TensorFlow, ROCm/HIP, JAX, or Vulkan Compute).

NATIVEON standard library dependencies:
* Rust Standard Library (`std`)
